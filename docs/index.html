Inkhue

A black-and-white print that carries its own color.

Print a color photo or document on any black-and-white printer — it looks like an ordinary grayscale page. Scan it, and Inkhue brings the color back. Free and open source.

How to use

1

Install

macOS, Windows or Ubuntu/Debian installer. Updates itself.

2

Hide color

Load a photo, image or PDF. Inkhue makes the black-and-white page, as large as your paper allows.

3

Print

From Inkhue's print panel at 100 % scale, on any black-and-white printer.

4

Reveal color

Scan in grayscale at 600 dpi (400 at least). The color comes back — export it as PNG, JPEG or PDF.

How it works

Dots carry data

Every pixel is a 4×4 cell of printer dots. How many dots are inked sets the gray; which corner the ink leans towards stores 2 bits — about 5.6 KB per square inch.

Built to survive

Color at 1/8 resolution, Reed-Solomon error correction, repeated across the page and scattered. Smudges, handwriting, tilt and upside-down scans are fine.

Neural refiner

A small network reads the scan dot by dot and returns the photo at 2× resolution, without grain.

Open by design

No key, no encryption, no account. Hidden from the eye, not from people. Apache-2.0.

The full story, step by step, is in the README and the wiki.
